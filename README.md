# Multi-Disease Prediction System Using Machine Learning

## Project Overview
This project focuses on predicting multiple diseases using machine learning techniques. It includes prediction modules for diabetes, heart disease, and chronic kidney disease (CKD).

## Diseases Covered
- **Diabetes Prediction:** Uses Support Vector Machine (SVM) with the Pima Indians Diabetes Dataset.
- **Heart Disease Prediction:** Uses Logistic Regression and Random Forest with the UCI Cleveland Heart Disease Dataset.
- **Chronic Kidney Disease (CKD) Prediction:** Uses Random Forest.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Data Preprocessing
The project uses data preprocessing techniques such as:
- Missing-value handling using median and mode imputation
- Label encoding
- Feature scaling using StandardScaler
